# ⚔️ وقایع‌نگاری اِلدوریا — نسخه آزمایشی مینی‌اپ تلگرام

یک پروتوتایپ ساده و کامل از بازی نقش‌آفرینی فانتزی به سبک مینی‌اپ‌های تلگرام (الهام‌گرفته از الدوریا).

## ویژگی‌ها

- ✅ انتخاب کلاس (جنگجو / جادوگر / نکرومانسر)
- ✅ سیستم سطح‌بندی و تجربه (XP)
- ✅ مبارزه نوبتی با مهارت‌های مخصوص هر کلاس
- ✅ اکتشاف و رویدادهای تصادفی
- ✅ کوله‌پشتی و فروشگاه
- ✅ ذخیره خودکار پیشرفت (localStorage)
- ✅ پشتیبانی کامل از Telegram WebApp API
- ✅ رابط کاربری کاملاً فارسی و راست‌چین
- ✅ طراحی موبایل‌فرست و تاریک

## نحوه راه‌اندازی

### ۱. تست محلی
فقط فایل `index.html` را در مرورگر باز کن.  
(برای تست کامل WebApp بهتر است از طریق تلگرام اجرا شود)

### ۲. ساخت بات و مینی‌اپ

1. به [@BotFather](https://t.me/BotFather) پیام بده
2. دستور `/newbot` را بزن و نام و یوزرنیم بات را مشخص کن
3. توکن بات را ذخیره کن
4. دستور `/newapp` را بزن و بات را انتخاب کن
5. عنوان و توضیح مینی‌اپ را وارد کن
6. عکس و GIF اختیاری آپلود کن
7. **URL** را آدرس هاست‌شده پروژه قرار بده (مثلاً لینک Vercel یا GitHub Pages)

### ۳. هاست رایگان (پیشنهادی)

#### روش A — Vercel (ساده‌ترین)
```bash
# اگر Node نداری فقط فایل‌ها را آپلود کن
npx vercel
```
یا پوشه را در [vercel.com](https://vercel.com) بکش و رها کن.

#### روش B — GitHub Pages
1. ریپوی جدید بساز
2. فایل‌ها را آپلود کن
3. Settings → Pages → Source را روی main بگذار

### ۴. اتصال به بات

بعد از گرفتن URL:
```
/setmenubutton
```
در BotFather → باتت را انتخاب کن → URL مینی‌اپ را بگذار.

یا در کد بات (Node.js مثال):

```js
bot.setChatMenuButton({
  menu_button: {
    type: 'web_app',
    text: '🎮 ورود به الدوریا',
    web_app: { url: 'https://your-app.vercel.app' }
  }
});
```
